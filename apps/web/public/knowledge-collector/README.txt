Delegate 网页知识采集（Chrome / Edge）

首次安装：
1. 解压此 ZIP，保留整个文件夹。
2. Chrome 打开 chrome://extensions（Edge 打开 edge://extensions）。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择该文件夹。
4. 可将“Delegate 网页知识采集”固定到工具栏。

采集流程：
1. 在同一个浏览器打开需要的网页，手动完成登录或安全验证。
2. 等待正文加载并展开折叠部分。飞书文档会自动从头滚动到末尾合并正文，忽略可能不完整的旧选区，并恢复原位置。普通网页可先选中希望采集的正文。
3. 点击扩展 → “验证完成，采集正文”，采集中请保持窗口打开。核对开头、末尾和章节后保存采集文件。
   若长文档在 60 秒内无法确认加载完成，会明确报错，请稍后重试或导出原文件。
4. 回到 Delegate 的“导入网址 → 浏览器采集”，选择文件，核对来源、正文和可见范围后导入。
5. 已失败的网址可在知识详情点击“浏览器采集”，补充正文而不创建重复资产。

工具支持浏览器能访问的内网和已登录页面；它不会绕过验证码或账号权限。
工具只在点击时读取当前页面可见文本/选中文本，不读取 Cookie、密码、其他标签页，不主动发送网络请求。
文件保留来源网址、标题、正文和采集时间。请按资料保密要求保管或在导入后自行删除。
当前不支持 Safari、PDF 浏览器页、画布正文和跨域 iframe 正文；此类内容请另行上传原文件。
