# r003 Web citations and episode context verification

Date: 2026-11-23. Base: dev `9bb2e1e607c5b0528cfffe316346e32468242a0f`; branch `codex/r003-citation-context`. This report records local verification; it does not assert production deployment, medical correctness, or live payment acceptance.

## Behavior

Web answers use reference markup that is parsed before delivery into LF Markdown and UTF-16 half-open ranges. Each range binds to sources actually acquired and authorized in that run. Episode ordinals identify immutable source versions without granting permission. One answer-only correction/self-check shares the original run and execution budget. Telegram and Matrix retain their existing citation/history contract.

Three additive tables store episode sources, message ranges and range/source acquisitions; the existing MessageCitation model remains compatible. Final body and annotations commit together. New reads validate the body hash and annotation manifest and fail closed on corruption. Recently completed user/assistant pairs are replayed within the same episode; revoked dependencies are masked in the model copy, with original and derived input proofs revalidated at model/release/delivery boundaries.

The Markdown UI supports tables, deletion and read-only task lists. Citation cards recheck source permissions on every open, expose only titles, ignore stale responses, preserve keyboard focus, and avoid navigation, HTML execution and model-image requests. User attachment handling remains separate. The existing display acknowledgement now queries the conversation channel string `web` rather than the memory channel enum `WEB`.

PI's empty-tools serialization is normalized after encoding without changing tool history or adding retries. Output defaults to 8192 tokens; the existing configured context window and other execution budgets remain. The actual SDK clamp is checked before admission: a smaller output ceiling alone does not disable tools, and a ceiling below 1024 stops before sending a provider request. Matching final answer-state closing tags are removed before computing citation coordinates, while code examples remain literal.

Full local JSONL tracing is opt-in through DELEGATE_LOCAL_TRACE_ENABLED and an absolute DELEGATE_LOCAL_TRACE_DIR. It is separate from public/database diagnostic traces, excludes credentials/hidden reasoning/binary content, and should only be enabled in an appropriate local test environment.

## Limits and rollback

Citation format validity and source authorization do not prove semantic support. Actual retrieval still may return a fixed 4000-character document prefix; query coverage, repeated evidence in the loop, failed-question retry, and temporary formatting preferences leaking through history are separate deferred work. Intermittent provider empty responses have been observed; this change does not add an unbounded retry policy or promise all model answers succeed. Existing billing policy remains, including partial-answer accounting.

HTTP destructive scenarios used newly created synthetic representatives, which were archived afterward and retained by explicit IDs for audit; existing long-lived fixtures were not revoked, reset or deleted. A separate local import of six user-provided source sections is test-environment work, not application source or an assertion that their medical claims have been verified.

Rollback uses the previous application image and stops reading the optional new annotation fields. Keep the additive tables and original messages. Do not drop long-lived volumes or rewrite old citations. Verification does not archive OpenSpec or merge the PR.
