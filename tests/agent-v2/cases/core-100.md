# Agent V2 100 条核心验收用例

版本3，2026-10-22。需求编号见[覆盖矩阵](../coverage-matrix.md)，数据见[清单](../fixtures/manifest.md)。本批登记 {'PASS': 13, 'NOT_RUN': 82, 'FAIL': 2, 'BLOCKED': 3}；详见[保留报告](../../../reports/agent-v2/core-100/20261022-remediation/report.md)。NOT_RUN可包含已观测但未完成全部变体的用例，细分见case-results.json；不继承历史PASS。

所有用例默认使用 ENV-01、DATA-01 和 [EV-01 证据合同](../README.md#证据合同)。P0不能通过平均通过率抵消失败。R=真实模型，S=受控机制，E=真实产品链路；多种标记表示这些维度均须验证，R+E可以合并在一次真实产品运行，S不能代替R/E。R用例不预设模型tool-call序列。恢复类定向故障要标明注入条件，不用它证明模型自主初始选择。

预期行为是验收标准，包含可能暴露当前缺陷的要求，并非声明当前实现已全部满足。每个变体新会话，明确的多轮步骤除外；“0次业务工具”不禁止request_clarification等控制工具。对话接口HTTP200/202或GenerationRun已交付不是任务成功证明。
